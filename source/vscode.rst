
==============================
Setup e Dicas do VS Code
==============================

O Visual Studio Code é o nosso ambiente central. Veja como configurar a ferramenta para obter o máximo de produtividade.

Instalação Segura
=================
Recomendamos a instalação silenciosa via gerenciador de pacotes do Windows. No PowerShell (como usuário padrão), execute:

.. code-block:: powershell

   winget install Microsoft.VisualStudioCode

Extensões Recomendadas
======================
Para transformar o VS Code em uma verdadeira central de controle, instale estas extensões na aba lateral (``Ctrl + Shift + X``):

.. grid:: 1 2 2 2
   :gutter: 3

   .. grid-item-card:: 🐍 Python (Microsoft)
      
      Essencial para auto-completar scripts, debugar código e gerenciar o ambiente de compilação do Sphinx.

   .. grid-item-card:: 📝 reStructuredText (LeXtudio)
      
      Habilita o realce de sintaxe (cores) e atalhos para os arquivos ``.rst`` da nossa documentação.

   .. grid-item-card:: 👁️ Live Preview (Microsoft)
      
      Permite hospedar um servidor local instantâneo para vermos o site gerado lado a lado com o código.

   .. grid-item-card:: 🎨 Material Icon Theme
      
      Altera os ícones das pastas e arquivos, facilitando a identificação visual rápida de logs, scripts e textos.
